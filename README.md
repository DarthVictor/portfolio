# Darth Victor portfolio

A static Astro portfolio built with TypeScript, MDX, and optional Preact islands.

## Requirements

- Node.js 24.x
- pnpm 11.x

## Commands

```sh
pnpm dev
pnpm build
```

Run `pnpm dev` to start the local site. Run `pnpm build` before deploying the generated `dist` directory.
